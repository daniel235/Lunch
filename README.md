# Lunch

A weekly lunch and dinner planner that runs as a single web page.

- Plan 14 meals a week and see what each choice adds to the grocery bill
- Keep a pantry so you only buy what you are missing
- Build a shopping list, approve it, then open each item at H-E-B or Walmart
- Set a weekly budget and your own ingredient prices

## Run it

Open `index.html` in a browser, or turn on GitHub Pages for the `main` branch and visit `https://daniel235.github.io/lunch/`.

Your plan is saved in the browser on the device you use. Prices are estimates you can edit, not live store prices.
